# lorotravels/.github

Este repositório guarda o **perfil da organização [Loro](https://github.com/lorotravels)** no GitHub e os **arquivos padrão da comunidade**.

## O que há aqui

| Arquivo | Para que serve | Estado |
| ------- | -------------- | ------ |
| [`profile/README.md`](./profile/README.md) | README de perfil, exibido na página da organização | ✅ |
| `profile/assets/` | Imagens usadas pelo README de perfil (logo) | ✅ |
| `CODE_OF_CONDUCT.md` | Código de conduta | 🔜 |
| `CONTRIBUTING.md` | Como contribuir | 🔜 |
| `SECURITY.md` | Como reportar uma vulnerabilidade | 🔜 |
| `SUPPORT.md` | Onde pedir ajuda | 🔜 |
| Modelos de issue e de pull request | Padronizar relatos e revisões | 🔜 |

Este repositório é **público**: nada aqui deve conter segredo, dado pessoal ou informação interna.
